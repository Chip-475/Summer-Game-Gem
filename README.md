# *Last CALL*
At this moment, 08/24/2026, the game beta is available. The game is structured with a main menu that, with a save system, allows you to start a new game, continue an existing one, or exit. After that, you go through the first introductory scene of the story and then to the actual game with the bar, the bottles, the customers coming in, the shop system, coins, storage, and recipe book if you don’t know a drink. But when it’s fully ready, it’ll be even better.  

For the download, go to the Hitc page that’s linked.  

Also, the use of AI in this project was more like help for some ideas and a bit of support in the code for debugging or lack of knowledge. If I had a question, I’d ask how to do it and then handle it myself. For most of the graphics, there are recordings on Lapse.
